# 通用查询与权限投影

本目录提供可序列化的查询、保存视图、角色、能力和作用域契约，以及不依赖 HTTP、React、数据库或具体工程的纯查询执行器。

当前可用范围：

- 对受控运行快照执行实体、组件和关系过滤与投影。
- 以稳定实体 ID 作为最终排序键，在同一快照修订上进行游标分页。
- 按修订筛选增量实体与指标，并聚合权限范围内的指标。
- 在过滤、排序和投影前执行实体、字段、关系与指标级读取裁剪。
- 通过保存视图复用同一查询定义；标记为 `planned` 的视图会被拒绝执行。

仍为 `planned`：

- HTTP 路由与 React hooks 接入。
- 持久化查询视图仓库、历史修订快照和带签名的外部游标。
- 事件与资源账本聚合。这些数据源尚未进入通用运行快照契约。

调用方只能向服务端查询服务提供 `runId`、共享查询和观察者身份。数据库连接、表名和任意 SQL 不属于共享契约，也不会传给普通观察者。
