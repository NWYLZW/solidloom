# 通用实体交互界面规范

本文件适用于 `apps/web/src/interaction-ui` 及其子目录。仓库根目录的协作规范继续生效。

## 定位

- 本目录提供与领域无关的实体交互表面，例如容器、设备、对话框和快捷操作。
- 组件输入必须是能力、状态、动作和文案等语义数据，不能内置售货机、咖啡机、饮水机或某个游戏的业务规则。
- 领域项目通过 renderer、slot、文案和 CSS 变量定制；默认 renderer 必须在不定制时仍可完整使用。

## 结构与状态

- controller/hook 负责状态和动作，renderer 负责语义结构，CSS 负责外观；不能把业务状态机写进样式组件。
- 公共交互优先扩展 `InteractionUIProvider`、renderer 和 slot 契约，不通过复制默认 renderer 建立近似版本。
- 根节点提供稳定的类名与 `data-interaction-*`、`data-state`、`aria-*` 状态，方便调用方无侵入定制。
- 默认使用原生表单控件和按钮；对话框统一支持 `Escape`、焦点恢复和明确的初始焦点。

## 白板式默认 renderer

- 默认 renderer 使用低装饰的纯色表面、单层边框和清晰分隔，避免毛玻璃、渐变、发光、纹理、重阴影和多层卡片。
- 可以借鉴成熟系统界面的信息组织、对齐、控件语义和状态反馈，但不得复制特定平台的品牌视觉。默认交互应像可换肤的系统控件，不像写死主题的游戏 HUD。
- 信息层级优先依赖布局、留白、字号和字重；说明文字不自动进入卡片。
- 相同语义控件共享组件和选择器。容器与设备 renderer 不得分别实现视觉不同但行为相同的按钮、选项或表单行。

## CSS 定制契约

- 所有视觉值通过 CSS 自定义属性读取，通用交互使用 `--interaction-*` 前缀并回退到全局设计变量。
- 不在组件局部重新声明调用方需要覆盖的公共变量；使用 `var(--interaction-xxx, fallback)`。
- 禁止通过内联样式注入主题颜色，禁止要求调用方覆盖深层 DOM 或 `:nth-child`。
- 公共变量、slot 和 renderer 扩展点变更时同步更新本目录 `README.md`。
- 自定义主题不得改变交互语义、焦点顺序、可访问名称或动作授权规则。

## 验证

- 至少验证默认 renderer、自定义 renderer/slot、键盘关闭、焦点恢复、窄屏和深浅主题。
- 未完成的 renderer 或动作必须明确标记 `planned`，不能用只有视觉反馈的按钮伪装可用能力。
